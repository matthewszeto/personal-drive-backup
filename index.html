Personal backup tool

Matthew’s Personal Drive Backup

I use rclone on my Windows computer to back up folders I choose to my Google Drive. I use Google sign-in to give rclone access to my account.

How I back up a folder

  1. Choose the folders

    I select a source folder on my computer and the destination folder in my Drive.

  2. Copy to Drive

    Rclone finds the destination, uploads the selected files and preserves their folder structure.

  3. Check the copies

    I compare names and sizes, and use file checksums where available, before deciding whether to remove a local copy.

Why the tool requests Drive access

I use existing folders as well as new ones. Drive access lets rclone find those folders, check files already there and retrieve a backup when I need it.
