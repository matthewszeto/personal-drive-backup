Matthew’s Personal Drive Backup

Privacy policy

Effective 31 October 2026

I’m Matthew, the operator of this personal backup tool. This policy covers my desktop rclone setup and these public information pages.

What the tool can access

Google’s full Drive permission allows rclone to read, create, edit and delete files that my connected account can access. I use it to locate backup folders, upload selected files, check existing copies and restore files I choose.

A transfer reads file contents and uses metadata such as names, folder paths, Drive file and folder IDs, sizes, modification times and checksums where available. A restore or a content comparison can download file contents from Drive.

Where the data goes

Rclone transfers backup data between my computer and Google Drive over HTTPS. Google stores the remote copies in the account I authorize. Access to those copies follows the folders’ and files’ Drive sharing permissions.

Rclone keeps the Google authorization tokens in its configuration under my Windows account so that later transfers can run. Local transfer and verification records can contain file names, paths, sizes, checksums and results.

I use Google API data only for the backup, verification and restore operations I request. I do not sell it or share it for advertising. My use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and revocation

I keep backup copies in Drive until I delete them. Drive’s Trash settings govern removal after deletion. I keep local records until I delete them from my computer.

To stop future access, I can remove this app in Google Account connections and remove the saved connection from rclone. To remove previously uploaded copies, I delete them in Drive separately.

Visiting these pages

GitHub Pages hosts these static pages. GitHub receives ordinary web requests and logs visitors’ IP addresses for security. This site has no upload form, sign-in form or analytics scripts. Backup files and Google authorization tokens stay separate from this site. Read the GitHub General Privacy Statement for GitHub’s hosting practices.

Contact

For a privacy question or a deletion request, contact me using the support email shown on the app’s Google consent screen. My public profile is matthewszeto on GitHub.
